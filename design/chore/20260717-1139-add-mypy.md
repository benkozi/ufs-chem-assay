# Chore: mypy for all source + pre-commit (ruff format, mypy)

## Goal

Add mypy checking over everything under `src/` (runtime modules, models,
and both test suites), fix every finding with real types — `Any` only where
the domain is genuinely open — enforce that no function or method is
untyped, and wire a pre-commit configuration that runs ruff formatting and
mypy on every commit.

## Pre-design audit (probe runs against the current tree)

A scoping run (`--disallow-untyped-defs --warn-return-any`, `MYPYPATH=src`,
`--explicit-package-bases`) shapes everything below:

1. **The pydantic mypy plugin is the single biggest lever.** Without it:
   187 errors, dominated by 126 spurious `call-arg` ("missing named
   argument") from mypy's `dataclass_transform` view of `Field(...)`
   defaults. With `plugins = ["pydantic.mypy"]`: **56 errors**. The plugin
   is required config, not optional polish.
2. **Residual profile (56), by category**:
   - 22 `arg-type` — all one call site: `comparison.py:374` passes
     `**kwargs: dict[str, object]` to `xr.open_dataset`, fanning into one
     complaint per overload parameter. One precise-typing fix.
   - 19 `no-untyped-def` — unannotated test helpers/fixtures spread over
     six test files.
   - 5 `no-any-return` — session fixtures returning
     `request.config._combo_*`: dynamically-stashed attributes are `Any`,
     which the existing `type: ignore[attr-defined]` comments don't cover.
   - 5 `attr-defined` — `suite_config.py:48,53` (an enum class typed as
     bare `type`, not `type[<Enum>]`, so iteration doesn't typecheck);
     `plotting.py:150` (`Image.ADAPTIVE` — moved to `Image.Palette` in
     modern Pillow); `test_plotting.py:98,210` (`n_frames` missing from
     the base `ImageFile` stubs; the object is a `GifImageFile`).
   - 4 `import-untyped` — cartopy modules only; **no stubs exist** →
     per-module override, not a global escape hatch.
   - 1 `call-overload` + 1 stray — `test_comparison.py:51` builds a
     `to_netcdf` encoding dict typed `dict[Hashable, dict[str, None]]`.
3. **Stubs**: `pandas-stubs` and `types-PyYAML` silence pandas/yaml;
   xarray, matplotlib, Pillow, dask, pydantic, python-ulid all ship types.
   Only cartopy is untyped.
4. **Module layout needs two switches**: flat first-party imports
   (`from settings import Settings`) need `mypy_path = "src"`, and the two
   `conftest.py`/duplicate test-module basenames need
   `explicit_package_bases = true`.
5. **Existing `type: ignore` inventory**: 32 comments, almost all
   `[attr-defined]` on `config._combo_*` reads/writes in
   [conftest.py](src/tests/conftest.py) — symptoms of stashing state as
   untyped attributes on `pytest.Config` (same root cause as the
   `no-any-return` group).
6. **Existing `Any` usage is minimal**: `analysis._time_fields ->
   dict[str, Any]` and `cece_config.options: dict[str, Any]` — candidates
   for tightening under the new "avoid `Any`" rule.

## Design

### Tooling: dev dependency group + config in `pyproject.toml`

- `[dependency-groups] dev = ["mypy>=1.14", "pandas-stubs", "types-PyYAML",
  "pre-commit"]` — installed by default with `uv sync`; runtime deps
  untouched.
- `[tool.mypy]` in `pyproject.toml` (beside the pytest config; no new
  config file):
  - `files = ["src"]`, `mypy_path = "src"`,
    `explicit_package_bases = true`, `python_version = "3.11"`
    (matches `requires-python` / ruff `target-version`).
  - `plugins = ["pydantic.mypy"]`, with `[tool.pydantic-mypy]`
    `init_typed = true` and `init_forbid_extra = true` — constructor
    checking consistent with the `StrictModel` extra-forbid convention.
  - Strictness: `disallow_untyped_defs`, `disallow_incomplete_defs`
    (the "no untyped functions or methods" requirement, tests included),
    `warn_return_any` (no `Any` leaking through typed signatures),
    `warn_unused_ignores` (stale `type: ignore` comments are errors, so
    the ignore inventory can only shrink), `warn_redundant_casts`.
  - `disallow_any_generics` is **deferred**: today's violations are
    third-party-shaped (pandas/xarray idioms), and the always-do rule is
    served by `warn_return_any` + review; noted as future tightening.
  - Per-module override for the only untyped library:
    `[[tool.mypy.overrides]] module = "cartopy.*"`,
    `ignore_missing_imports = true` — scoped, never global.

### Fix plan, by root cause (not per-error)

- **Typed session state on `pytest.Config` (fixes the 5 `no-any-return`
  and retires most of the 32 ignores).** Replace every dynamic
  `config._combo_*` attribute with module-level
  `pytest.StashKey[...]` instances (`pytest.Config.stash` is pytest's
  typed mechanism for exactly this): `StashKey[Settings]`,
  `StashKey[SuiteConfig]`, `StashKey[ComboRoots | None]`,
  `StashKey[list[Combo]]`, `StashKey[str]` (run id),
  `StashKey[dict[str, ResolvedBaseline]]`,
  `StashKey[dict[str, TestReportRow]]`. Reads/writes go through
  `config.stash[key]` (typed both directions); the
  hookwrapper/sessionfinish getattr-with-default reads become
  `config.stash.get(key, default)`. No behavioral change — same
  lifecycle, same single writer at sessionstart.
- **`comparison.py:374`**: type the open-dataset kwargs precisely (a
  `TypedDict` or inlined literal arguments, whichever reads better at the
  call site) — collapses 22 errors.
- **`suite_config.py:48,53`**: annotate the enum-class value as
  `type[<the enum base>]` so iteration and `.value` access typecheck.
- **Pillow**: `Image.Palette.ADAPTIVE` in `plotting.py`; in the GIF
  assertions, narrow the opened image to `GifImagePlugin.GifImageFile`
  (isinstance-assert, which is also a stronger test) before `n_frames`.
- **19 `no-untyped-def`**: annotate the test helpers/fixtures
  (`-> None` tests, typed fixture params — mirroring the annotated style
  the newer test files already use).
- **`test_comparison.py:51`**: type the encoding mapping to what
  `to_netcdf` accepts.
- **Existing `Any`s (audit #6)**: `_time_fields` returns
  `dict[str, int | str | None]`-shaped data — give it the precise union;
  `cece_config.options` stays permissive **only if** the driver contract
  is genuinely open — if so it keeps `dict[str, Any]` with a comment
  saying why (the allowed, documented exception), otherwise tighten to
  the YAML-scalar union.
- Anything that surfaces beyond the probe's 56 is fixed with real types;
  new `type: ignore[<code>]` is a last resort and must be code-scoped.

### Pre-commit: local hooks through uv

`.pre-commit-config.yaml` at the repo root using `repo: local` +
`language: system` hooks that shell out to `uv run` — the project venv is
the single source of tool versions (no `mirrors-mypy` isolated
environment, which would miss the pydantic plugin and every dependency):

- `ruff-format`: `uv run ruff format` on staged Python files (mutates and
  fails the commit for restaging, standard ruff-hook behavior).
- `ruff-check`: `uv run ruff check` (lint alongside formatting; the repo
  already treats `ruff check` as a gate).
- `mypy`: `uv run mypy` with `pass_filenames: false` (whole-`src/` run —
  per-file mypy is unsound across module boundaries).

Setup step documented in the README: `uv run pre-commit install`.

### YAML lint/format + whitespace trimming (follow-up requirement)

- **YAML linting**: `yamllint` — and **formatting**: `yamlfix` — both PyPI
  packages, so they join the dev group and run as `uv run` local hooks
  exactly like ruff/mypy (single tool source, no isolated-env drift).
  - `yamlfix` configured in `pyproject.toml` `[tool.yamlfix]` to minimize
    churn on the checked-in suite/driver configs: no forced `---` document
    start, block-style sequences preserved. Reformatting is
    semantics-preserving (combo ids hash combination *values*, not file
    bytes), verified by the standing test battery.
  - `yamllint` configured in `.yamllint.yaml` (`extends: default`) with
    the pair kept coherent: `document-start` disabled to match yamlfix,
    line length relaxed.
  - **Scope**: `src/` YAMLs plus repo-root dotfile YAMLs. `design/` is
    excluded everywhere — spike artifacts and design records are records,
    not maintained code.
- **Whitespace trimming**: `trailing-whitespace` (with
  `--markdown-linebreak-ext=md`, so Markdown hard line breaks survive) and
  `end-of-file-fixer` from the canonical `pre-commit/pre-commit-hooks`
  repo. These are the one deliberate exception to the local-hooks rule:
  they have zero project-dependency coupling, so the isolated-env concern
  that mandates `uv run` for mypy does not apply. Same `design/`
  exclusion; `uv.lock` excluded (generated).

## Implementation notes

- Implemented as designed, with two deviations found during the work:
  - **`python_version` is deliberately unpinned** in `[tool.mypy]`: the
    venv runs Python 3.14 and numpy's stubs use 3.12+ `type` statements,
    so pinning 3.11 (the `requires-python` floor) breaks stub parsing.
    Checking runs against the interpreter that actually executes the code.
  - **The StashKey refactor surfaced a hidden consumer**:
    `test_driver_combos.py` read `config._combo_baselines` behind a
    pre-existing `type: ignore[attr-defined]`, which kept suppressing the
    (now-real) error after the attribute was removed — mypy stayed green
    while the integration run failed. Fixed properly with a
    `baseline_comparisons` session fixture (the stash keys stay private to
    the conftest). Lesson recorded: an ignore that suppresses a *real*
    error is invisible to `warn_unused_ignores`; the integration run is
    what caught it.
- Precise typing surfaced and fixed latent looseness beyond the probe:
  `_time_fields` and `_VDIST_COMPANIONS` became `TypedDict`s so their
  `**`-unpacks typecheck; `test_report`'s row helper now takes the
  `TestResult` literal (the deliberate-invalid-input test carries the one
  new, commented, code-scoped ignore); `_write_nc`'s `fmt` is the netCDF
  format literal.
- Four `type: ignore`s survive in `src/`, all load-bearing and
  code-scoped: `Operation.replace` (shadows `str.replace`) and three
  deliberate-invalid-input tests — the bad literal in `test_report.py`,
  the unknown-kwarg rejection in `test_plotting.py` (now statically
  flagged too, thanks to `init_forbid_extra`), and the frozen-assignment
  test in `test_settings.py`. All 28 others are gone.
- Verified: `uv run mypy` — 0 errors in 31 files; harness 147/147;
  exhaustive suite `--dry-run` 1440 skips; `simple-maccity-suite.yaml`
  integration 18/18 with the real driver;
  `uv run pre-commit run --all-files` passes (hooks installed).
- **YAML/trimming follow-up**: implemented as designed. yamlfix's one-time
  reformat of the four checked-in configs was reviewed and is
  semantics-preserving (quote normalization — regex sweeps like `".*"`
  stay strings unquoted — comment spacing, block-style lists; comments
  preserved). Re-verified afterwards: pre-commit idempotent-green across
  all seven hooks, harness 147/147, **both** exhaustive suites dry-run
  green (1440 skips each — the asserted variant's first harness exercise),
  integration 18/18.
