# Feature: retire the `combo-test-runner` identity (Phase A of the CATChem plan)

## Goal

Carry out the rename decided in
`design/spike/20260901-1229-rename-and-plan-for-catchem.md` (Phase A of
its phased plan): every place that still says the *old identity* —
`cece-combo-test-runner` (repo), `combo-test-runner` (project, image
tags, prose), `combo_test_runner` (logger namespace, harness test
package), `ctr` (its abbreviation) — moves off it, and the harness
suite, all suites in `--dry-run`, pre-commit, and both CI workflows
pass afterwards. Identity only: **no behaviour change, no CATChem, no
CECE-facing change.** `cece/cece-dev`, the `CECE_*` environment,
`--cece-root-dir`, `cece_config.py`, `src/tests/config/cece/`,
`cece_commit` in run.yaml, and every "combo" that means *combination*
(`combos.py`, `combos.csv`, `--combo-*` flags, `test_driver_combos.py`,
"per-combo tests") are out of scope by definition — they are not the
tool's name.

Second objective (user direction, 2026-09-01): **the repository name
may change again, so the tree should barely know it.** The rename
therefore does not swap one hard-coded repo name for another. Prose
says *the harness*; paths are repo-relative and never prefixed by a
repository directory; the few identifiers that must carry a name use
the bare tool word `assay`, and those live behind one constant where
code is involved. The literal `ufs-chem-assay` is confined to GitHub,
the spike, and this doc.

The `design/` folder is swept for **consistency, not rewritten**: path
and command literals that denote the harness, its test package, or its
images are updated so the folder keeps working as a reference;
recorded artifacts and the spike's own "old → new" narrative stay as
they are.

## Naming scheme (decision)

| identity                        | today                                  | after                              |
|---------------------------------|----------------------------------------|------------------------------------|
| GitHub repo / local clone       | `cece-combo-test-runner`               | `ufs-chem-assay` (**done**)        |
| `pyproject.toml` `name`         | `combo-test-runner`                    | `assay`                            |
| `uv.lock` root package          | `combo-test-runner`                    | `assay` (via `uv lock`)            |
| CI toolchain image tag          | `combo-test-runner:ci` / `:dev`        | `assay:ci` / `assay:dev`           |
| logger namespace                | `combo_test_runner`                    | `assay`                            |
| harness test package            | `src/tests/combo_test_runner/`         | `src/tests/assay/`                 |
| integration output-root dir     | `ctr-ci-output`                        | `assay-ci-output`                  |
| plot footer                     | `Generated by CECE combo-test-runner`  | `Generated by assay`               |
| README title                    | `# combo-test-runner`                  | `# assay`                          |
| design.md title                 | `Combinatorial Test Runner — Design`   | `Harness design`                   |
| path prefix in docs             | `combo-test-runner/src/…`              | `src/…` (repo-relative, no prefix) |
| prose                           | "the combo-test-runner"                | "the harness"                      |
| repo name in the maintained tree| —                                      | **nowhere**                        |

Rules:

- **One constant in code.** `src/logs.py` gains
  `HARNESS_NAME = "assay"`; `LOGGER_NAME = HARNESS_NAME` and the
  plotting footer format from it. A future rename of the tool word is
  one line of Python plus the directory/tag/config sites listed above,
  all of which the identity test (below) enumerates.
- **Repo-relative paths only.** No document, comment, or script names
  the repository directory as a path component (`combo-test-runner/src`
  becomes `src`). The `README.md` already has no clone URL; it stays
  that way.
- **Descriptions are not names.** "combinatorial", "harness", "runner"
  as lower-case description stay wherever they read naturally
  (`conftest.py:99`'s option-group text "combinatorial driver test
  runner", `design.md:439` "beyond the test runner"); only the
  identity strings move.
- **The tool word is `assay`, not the repo name**, in every identifier
  (image tags included): identifiers should survive a repository
  rename untouched.

## Risks and notes

- **gha buildx cache**: the cache key is content-based, not
  tag-based; the image rebuild after the `uv.lock` one-liner is a
  near-total cache hit. The `integration` caches are scoped by CECE
  SHA and never mention the tool name.
- **Old links**: GitHub redirects `benkozi/cece-combo-test-runner`
  URLs and git remotes to the new name, so stale bookmarks keep
  working; nothing in-tree links to either URL.
- **A later repository rename** costs: GitHub rename, local clone
  rename, updating the spike/this doc if desired — and nothing in the
  maintained tree, which `test_repository_name_absent` enforces. A
  later *tool-word* rename costs `HARNESS_NAME`, the test directory,
  the image tags, `pyproject.toml`/`uv.lock`, `assay-ci-output`, and
  the README title — the sites the identity test enumerates.
